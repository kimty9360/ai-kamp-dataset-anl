# 이번 실험의 판단

기존 파일을 보존하고 CN7 좌우 CatBoost balanced, RG3 좌우 XGBoost balanced·SVM을 기준 후보로 계산했다. 원단위 복구·10개 파생변수·소규모 튜닝·학습폴드별 가중치 변경을 비교했으나, RG3의 높은 Recall과 높은 Precision을 동시에 확보하지 못했다.

## 진단

- RG3 불량25개는 RH의 가스17·미성형8이다. LH591행은 모두 양품이다.
- 생산일별 불량은 2020-10-21 0개, 22일15개, 23일10개다.
- RH 안에서 단일 변수 방향무관 AUC 최고는 Barrel_Temperature_5 약0.638, 다음 Plasticizing_Time 약0.562다. 이는 전체 데이터 탐색 통계로, 다변량 모델의 성능 상한을 의미하지 않는다.
- seed42의 기존 모델에서 두 불량 사유 모두 미탐이 존재한다. 특정 한 사유만이 전체 저성능의 원인이라고 단정할 수 없다.

## 입력·설정 변경

|RG3 모델|기존 좌우 AP|원단위 AP|원단위+파생변수 AP|파생변수+설정 변경 AP|파생변수+가중치 변경 AP|
|---|---:|---:|---:|---:|---:|
|XGBoost balanced|0.0753|0.0753|0.0599|0.0511|0.0604|
|SVM|0.0709|0.0709|0.0670|0.0670|0.0414|

원단위 복구만으로 입력 정보가 새로 생기는 것은 아니다. 이번 파생변수는 기존 변수로 결정되는 값이며 좌우 복구처럼 새로운 관측정보를 추가한 것이 아니다. 이번 후보가 개선하지 못했다는 결과이지, 모든 파생변수·튜닝이 불가능하다는 뜻은 아니다.

내부 precision95와 AP로 후보를 선택한 절차(inner_selected)의 외부 AP도 XGB0.0541·SVM0.0669로 낮아졌다. 새 설정을 주력 모델로 승격하지 않는다.

## Recall95% 목표 정책

아래는 기준 후보의 기존 입력·점수를 그대로 유지하고, 내부 OOF에서 Recall>=95%를 만족하면서 Precision을 최대화하도록 임계값을 정한 결과다. 숫자는 9개 외부 폴드 평균이다.

|데이터·모델|외부 Recall|외부 Precision|검사 대상 비율|외부 Recall95% 달성 폴드|
|---|---:|---:|---:|---:|
|CN7 CatBoost balanced|92.2%|5.2%|34.0%|6/9|
|RG3 XGBoost balanced|100.0%|2.7%|79.3%|9/9|
|RG3 SVM|89.9%|3.7%|53.1%|4/9|

폴드 평균은 불량수를 가중한 전체 행 집계와 다르다. 예를 들어 CN7은 각 seed에서17불량 중16개를 찾아 전체행 집계 Recall은 매회94.1%다. repeat_counts.csv에 TP·FP·FN·TN을 기록했다. 세 반복의 동일 불량을 서로 다른 독립 표본으로 계산하지 않는다.

## 다음 판단

- 기존 CN7 CatBoost·RG3 XGBoost/SVM은 비교 기준으로 유지한다. 운영 모델 확정은 아니다.
- 현재 실험으로 Recall95%와 높은 Precision의 동시 달성을 입증하지 못했다. 임계값 조정만으로 순위 구분력이 좋아지지는 않는다.
- RH 한정 모델, 시간·배치별 전이 점검, 추가 공정 정보 확보 등은 별도 후보이나 이번에 실행하지 않았다. 새 원자료의 좌우·시간 정보는 검증에 활용 가능하지만 Reason은 검사 후 정보로 입력 금지다.
- 미래/독립 생산기간 데이터 확보가 필요하다. 현재 범위는 기존 데이터의 반복 그룹 검증이며 실제 운영 성능을 보장하지 않는다.
