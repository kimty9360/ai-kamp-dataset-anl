# 데이터 의미 조사 기록 (2026-09-29)

## 배포 ZIP 원자료 연결로 갱신한 결론

사용자가 받은 `04. Dataset_Molding.zip`에서 8개 CSV를 확인했다. 전처리 소스코드는 포함되어 있지 않지만 1차 가공본과 더 앞 단계 데이터를 대조할 수 있다. 아래 결과가 이전의 미확인 상태를 갱신한다.

- 배포 ZIP의 가공 CSV 네 개는 현재 대회 파일과 바이트 단위로 동일하다.
- labeled_data.csv는 7996행이며 ID 중복이 존재한다. 중복 ID의 라벨은 모두 같아 ID·라벨 조합을 중복 제거한 뒤 moldset_labeled.csv의 2607행을 전부 연결했다. Y→0·N→1이 예외 없이 성립하며 라벨1에는 모두 불량 사유가 기록되어 있다. 가이드 실습과 합쳐 현재 0=양품, 1=불량으로 해석할 근거가 확보됐다.
- CN7은 1차 가공본 1425행의 앞 1211행, RG3는 전체 1182행을 각자 표준화하면 현재 공정값 24개가 최대 절대오차 4.2e-13 이내로 재현되고 행별 라벨도 전부 일치한다. 이는 실제 제공 파일에 대해 검증한 결과다. CN7 제외 214행에는 불량10행이 있으나 제외 이유는 미확인이다.
- 공정값만으로 묶은 충돌 36그룹(CN7 11, RG3 25)은 모두 같은 TimeStamp·EQUIP_CD의 LH/RH 2행이다. PART_FACT_SERIAL은 쌍 내에서 서로 다르므로 이것을 shot ID로 취급하지 않는다. 물리적으로 동일 shot인지는 별도 기록이 필요하다.
- 현재 데이터에서 CN7 불량은 LH 4·RH 13, RG3는 LH 0·RH 25다. 좌우 정보 추가가 타당한 다음 실험이다. 단순 라벨 오류나 복제본으로 보고 삭제해서는 안 된다.
- CN7 현재 17불량은 실제로 2020-10-16 05:21:38~05:57:20에 집중되어 있다. 파일 전체 행 순서는 단조 시간순이 아니므로 시간 분할은 복구한 TimeStamp를 사용해야 한다.

재현 코드: `scripts/audit_lineage.py`. 결과: [원자료 연결 보고서](../artifacts/lineage_v1/report.md). 행별 식별 정보는 로컬 rows/에만 저장한다. 과거 실험은 그대로 보존하며 의미 확인의 이력만 갱신한다.

## 로컬 PDF 이미지 확인으로 갱신한 결론

사용자가 제공한 `1.injection-molding/04.-Guidebook_Molding.pdf` 108쪽 중 43·62·69·70쪽을 이미지로 직접 확인했다. 아래는 앞선 공개 텍스트 조사보다 구체적인 근거이며, 이전 조사 기록은 아래에 보존한다.

- p.20: CN7·RG3를 자동차 사이드 몰딩 제품 두 종류로 설명한다. p.43은 EQUIP_NAME(설비)과 PART_NAME(제품)을 구분하며 CN7·RG3 각각 RH/LH 제품을 나열한다. p.62 코드도 제품 코드 두 개씩을 OR 조건으로 묶는다. 따라서 사출기 모델명이 아니라 좌/우 부품을 포함한 제품군 구분이다. 현재 중복이 좌/우에서 생겼다는 인과관계까지는 원본 ID 대조 없이 확정할 수 없다.
- p.69 코드42: PassOrFail==0을 양품, ==1을 불량품으로 집계한다. RG3 출력은 양품 1157·불량 25로 로컬 CSV와 일치한다. CN7 출력은 양품 1398·불량 27이며 현재 CSV의 1194·17과 다르다.
- p.69 코드41: 설명에는 Y/N 변환이라 쓰여 있으나 실제 이미지는 `{0:int(0), 1:int(1)}` 매핑이다. 이 코드는 숫자를 정수로 바꿀 뿐 라벨 방향을 뒤집지 않는다. 최초 Y/N 매핑은 이 이미지에서 증명되지 않는다.
- p.69 코드43: 네 데이터프레임 각각의 각 열에 StandardScaler를 새로 fit_transform한다. PassOrFail은 제외한다. 따라서 가이드의 처리 방식은 파일별·변수별 독립 표준화다. 배포 CSV가 이 코드로 바이트 수준에서 재현됐는지는 원자료가 없어 미검증이다.
- p.70 코드44·45: 현재 사용하는 네 CSV 파일명으로 저장한다. 현재 가공 파일의 해석은 가이드 실습 기준 0=양품·1=불량으로 보는 근거가 강해졌다. 앞쪽 표의 반대 정의와 CN7 건수 차이는 버전/오기/가공 차이 확인 사항으로 남긴다.

과거 실험 파일을 소급 수정하거나 라벨을 반전하지 않았다. 앞으로 설명 시 ‘가이드 실습 기준 0=양품, 1=불량; 배포 버전 정합성 확인 필요’라고 명시할 수 있다. 기존 예측 시점별 입력 가용성 문제와 독립 평가 필요성은 그대로다.
