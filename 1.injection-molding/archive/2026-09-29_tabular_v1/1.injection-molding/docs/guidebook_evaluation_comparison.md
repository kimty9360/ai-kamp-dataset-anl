# 가이드북 평가와 현재 실험의 비교

로컬 04.-Guidebook_Molding.pdf의 71·72·83·84쪽 코드 이미지와 표를 직접 확인했다. 87~90쪽의 수치는 데이터 품질 점검이며 모델 예측 성능과 구분한다.

## 정확도와 불량 검출

이진 분류에 공통으로 적용되는 95% 최소 성능 기준은 없다. 현재 CN7을 모두 양품으로 예측하면 정확도 1194/1211=98.596%, RG3는 1157/1182=97.885%이지만 불량 Recall은 0이다.

저장된 side_feature_v1/fold_metrics.csv에서 (TP+TN)/rows로 정확도를 재계산했다. 0.5 고정 정책, 9개 외부 폴드 평균에서 CN7 CatBoost(가중치 없음)의 기존 정확도는 99.09%, 불량 Recall은 39.68%, F1은 0.5554다. 좌우 추가 후 정확도는 99.06%, Recall은 37.83%, F1은 0.5316이다. RG3 같은 모델의 정확도는 기존/좌우 모두 97.88%지만 불량 Recall은 0이다. 정확도만 높여서 목표를 달성했다고 판단할 수 없다.

## 가이드북 결과도 실제로 높다

83쪽 RG3 Random Forest: 정확도 .98, Precision .91, Recall 1.00, F1 .95.
84쪽 CN7 Random Forest: 정확도 .99, Precision .97, Recall 1.00, F1 .98.
따라서 차이를 지표 혼동만으로 설명할 수 없다. 현재 모델의 불량 검출 성능도 개선할 필요가 있다.

## 평가 대상이 다르다는 증거

84쪽 혼동행렬에서 RG3 평가 불량은 83개(TP83+FN0), CN7은 56개다. 현재 가공 CSV의 전체 불량은 각각 25개와 17개다. 중간본에서도 RG3 25, CN7 27이므로 표는 현재 원래 행을 단순 분할한 평가가 아니다.

77쪽에는 오버/언더샘플링 가능성을 설명하고 75~82쪽에는 미라벨 데이터에 의사라벨을 붙이는 준지도학습이 설명돼 있다. 다만 이것만으로 표의 정확한 생성 과정이나 평가 표본 증대 이유를 확정할 수 없다. 재샘플링·파일 버전·예제 결과 차이 등을 재현 코드로 대조해야 한다. 가이드북 결과가 잘못됐다고 단정하지 않는다.

## 분할 방식 차이

72쪽은 StratifiedShuffleSplit(n_splits=1,test_size=.3,random_state=42)를 사용하며 공정 그룹 제약이 없다. 이를 현재 CSV에 적용하면:

|데이터|평가 행|평가 불량|학습에도 동일 공정값이 있는 평가 행|
|---|---:|---:|---:|
|CN7|364|5|248|
|RG3|355|8|257|

이 수치는 가이드북 전체 모델 재현 결과가 아니라 해당 분할 코드만 현재 데이터에 적용한 진단이다. 동일 공정값이 양쪽에 존재하면 독립성 문제가 생길 수 있지만, 일부 쌍은 반대 라벨이므로 분할 차이가 반드시 모든 점수를 높인다고 단정하지 않는다. 높은 가이드북 점수의 원인 전체를 이것으로 설명할 수 없다.

현재 실험은 원공정 그룹을 묶고 3 seeds×3 folds로 평가하며 좌우 실험에서는 동일 설비·동일 시각 기록도 분리되지 않음을 확인했다. 설정도 baseline 수준이며 가이드북의 준지도·튜닝 절차를 동일하게 재현한 것이 아니다.

71쪽 평가 함수는 roc_auc_score(y,y_pred)처럼 0/1 판정값으로 ROC-AUC를 계산한다. 현재 코드는 확률 점수를 사용하므로 ROC-AUC 계산도 다르다.

## 다음 대조 실험 제안

기존 결과는 보존하고, 동일한 현재 데이터·동일 Random Forest 설정에 대해 행 단위 분할과 공정 그룹 분할을 비교한다. 샘플링을 적용한다면 학습 폴드 내부에서만 수행하고 평가 데이터는 원래 분포로 유지한다. 이후 가이드북 준지도학습을 별도 재현한다. 이 문서 작성 시 추가 모델 학습은 하지 않았다.
