## 재현

프로젝트 루트에서:

```bash
conda activate kamp-base
python 1.injection-molding/scripts/review_sources.py --output 1.injection-molding/artifacts/source_review_rerun
```

스크립트는 ZIP 안의 CSV를 읽고 요약표를 만든다. 출력 폴더가 이미 있으면 같은 이름의 진단 표를 갱신하므로 비교 보존이 필요할 때는 새 출력 경로를 지정한다. 모델이나 원본은 변경하지 않는다. 795,315행 파일은 메모리로 읽으므로 수백 MB 이상의 여유 메모리가 필요하다.

| 파일 | 내용 |
|---|---|
| `file_inventory.csv` | 크기, 중복, ID, 기간 |
| `audit.json` | 라벨 의미·Reason·중복 ID·파일 간 이벤트 연결·ZIP 해시 |
| `feature_statistics.csv` | 열별 결측·0·범위·분위수 |
| `sensor_coverage.csv` | 설비별 센서 상수/0 비율 |
| `product_coverage.csv` | 파일·설비·부품별 개수와 기간 |
| `timestamp_intervals.csv` | 설비·부품별 중복 시각 제외 기록 간격. 공백 포함 |
| `reason_counts.csv` | 원행/고유 ID별 양불·Reason 수 |
| `labeled_daily_counts.csv` | 중복 ID 제외 일별 양불/사유 |
| `id_overlap.csv` | 파일 간 ID 교집합 |
| `aggregate_count_audit.csv` | `ERR_FACT_QTY` 후보 집계 단위 점검 |

고유 ID 집계는 중복 제거 학습 파일을 생성했다는 뜻이 아니다. 실제 샷 수·생산량이 확인되었다는 뜻도 아니다. 기간·분위수·임계값을 평가 데이터까지 보고 최적화하는 용도로 사용하지 않는다.
