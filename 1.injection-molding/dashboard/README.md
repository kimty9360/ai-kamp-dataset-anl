# 사출 공정 HTML 대시보드

노트북 셀 실행 없이 `labeled_data.csv`를 차종·좌우·날짜별로 탐색한다. 차종 선택의 ‘모델’은 CN7/RG3 등의 제품군을 뜻하며 학습 알고리즘 선택 화면은 아니다.

## 접속

로컬 서버 실행 중: **http://127.0.0.1:8765/**

완성 파일: `../artifacts/dashboard_v1/index.html`. Plotly 코드와 행별 데이터가 HTML 안에 포함되어 있어 파일 자체를 Windows 브라우저로 열어도 작동한다. 인터넷이나 Jupyter 커널이 필요하지 않다. Jupyter 미리보기 대신 위 로컬 주소 또는 브라우저의 파일 열기를 사용한다.

## 제공 기능

- CN7/RG3/JX1/SP2 및 전체 혼합 참고 자료 선택. LH/RH, 시작·종료 날짜 선택. 차종·좌우를 바꾸면 해당 자료의 전체 기간으로 초기화.
- 고유 기록·불량 기록·관측 비율·설비/날짜 수 표시.
- 날짜별 양불 기록 수. 날짜 막대를 누르면 해당 날짜로 필터.
- **공정 컬럼 36개 중 기본 전처리 후 남은 컬럼**을 시간축에 표시. CN7/RG3 전체 좌우 기준 각각 24개. 모두 0·비영 상수·전체 결측인 컬럼은 기본 제외하며 포함 체크로 복원. 시간·위치·속도/회전·압력·온도 구분 및 컬럼 검색.
- 동시각 좌우 비교: 동일 설비·제품·시각에 LH/RH가 각각 한 건씩 있는 경우만 짝지음. 한쪽만 불량인 시각을 선택하면 전후 15분과 해당 구간의 공통 세로축으로 확대. 상대쪽 기록이 없으면 양품으로 간주하지 않음.
- 양품과 가스/미성형/초기허용불량을 색·기호로 표시. 양품 숨김, 확대/복원, 툴팁, 그림 저장.
- 그래프 점 또는 불량 목록 행을 누르면 그 기록의 36개 공정값과 메타정보 확인.
- 선택 자료의 Pearson/Spearman 상관계수. 히트맵 소수 둘째 자리, 전체 표 소수 셋째 자리. 공정값–불량 상관도 별도 표시.
- 선택 행·분석 컬럼과 상관계수 CSV 저장. 제외 컬럼 포함을 체크하면 원본 36개 공정 컬럼을 저장. CSV에는 계산된 원래 수치 정밀도를 유지.

## 데이터·해석 원칙

원자료 7,996행 중 동일 ID의 완전 반복을 한 번만 세어 5,232기록을 넣었다. 원본은 수정하지 않는다. CN7 3,974기록/불량 28개, RG3 1,256/32개, JX1·SP2는 각각 양품 1개다. 같은 ID에 값이 다른 중복이 있으면 빌더가 중단한다.

공정값은 원단위로 유지하며 샘플링·집계로 시계열 점을 줄이지 않는다. 그래프는 화면 근처의 컬럼만 그렸다가 스크롤에 따라 갱신해 브라우저 부하를 줄이지만, **그려진 컬럼에는 선택된 모든 기록을 사용**한다. LH는 왼쪽, RH는 오른쪽 패널에 나란히 표시하며 동일한 시간축·값 범위를 사용한다. 한쪽에서 확대하면 반대쪽 축도 함께 움직인다.

시각은 CSV 표기 그대로이며 시간대·실제 결함 발생 시점이 확인된 것은 아니다. 같은 설비·제품·좌우의 관측을 시간순 선과 점으로 표시하며, 10분을 넘는 관측 공백에서는 선을 끊는다. 이 10분은 표시 기준이며 실제 공정 정지 판정 기준은 아니다. ‘공정 컬럼 전체’는 센서값 36개를 뜻하며 ID/생산일련번호를 연속 공정값으로 그리지 않는다. 메타정보는 기록 상세에 표시한다.

상관은 현재 선택된 부품 기록을 기준으로 계산한다. 상수·표본 부족은 미정의(—)로 표시한다. 혼합 제품·시간 의존·좌우 반복·희귀 불량의 영향을 받으며 인과/검증 성능을 뜻하지 않는다. 기존 노트북의 이벤트 가중 민감도 및 일자별 평균 차감 분석은 이 화면에서 다시 계산하지 않는다. 학습 모델의 성능표나 새 학습 기능도 포함하지 않는다.

JX1/SP2는 원자료 확인용이며 관측이 한 건뿐이므로 상관 계산이 불가능하다. 모델의 이상 점수·예측 불량을 표시하는 것이 아니라 **실제 PassOrFail 및 Reason**을 표시한다.

## 다시 만들기 / 서버 다시 켜기

프로젝트 루트에서:

```bash
conda activate kamp-base
python 1.injection-molding/scripts/build_dashboard.py
python -m http.server 8765 --bind 127.0.0.1 --directory 1.injection-molding/artifacts/dashboard_v1
```

빌더는 현재 대시보드 HTML·manifest를 갱신한다. 이전 버전을 보존하려면 `--output 1.injection-molding/artifacts/dashboard_v2`처럼 새 경로를 지정한다. 서버가 이미 실행 중이면 중복 실행하지 않고 브라우저를 새로고침한다. WSL 종료/재부팅 뒤에는 서버를 다시 실행해야 한다.

HTML은 실제 행별 자료를 포함하므로 Git에 올리지 않도록 `.gitignore`에 등록했다. 재현 코드·템플릿·집계 검증 기록은 별도로 관리한다. 학습 환경의 패키지 버전은 변경하지 않았다. 브라우저 자동 검증 도구는 임시 경로에 별도로 설치해 사용했다.

## 기본 전처리 (2026-09-30)

- 동일 ID의 완전 반복 2,764행 제거 → 5,232개 기록. 다른 ID/좌우 기록은 유지한다.
- 라벨 Y/N, ID, 날짜 및 숫자 타입·무한값을 검사하고 시간순으로 정렬한다. 공정값 결측은 0개다.
- 전체 제품에서 항상 0인 10개 컬럼: Mold_Temperature_1, 2, 5~12.
- CN7: 위 10개 및 Switch_Over_Position, Barrel_Temperature_7 제외 → 24개.
- RG3: 공통 10개 및 Barrel_Temperature_7(모두 0), Clamp_Open_Position(비영 상수) 제외 → 24개.
- 화면의 제외 판단 범위는 선택한 제품·좌우의 **전체 기간**이다. 날짜 확대에 따른 일시적 상수화를 전역 상수로 취급하지 않는다. JX1/SP2의 단일 관측은 비영 상수 판정에 쓰지 않는다.
- 전처리 안내에서 제외 이유·값을 확인하고 포함 여부를 바꿀 수 있다. 시간 그래프·상관계수 표·불량 상관·CSV에 동일한 컬럼 선택을 적용한다. 기록 상세는 원본 36개 공정값을 유지한다.
- 원본 ZIP, 라벨, 비정상적으로 보이는 극단값, 부분적인 0은 수정하지 않는다. 스케일링·보간·임의 결측 대체도 하지 않는다.
- 자동 진단 결과: `../artifacts/dashboard_v1/preprocessing_report.json`. 이는 EDA용 규칙이며 향후 예측 모델 전처리의 통계량은 학습 분할에서만 추정해야 한다.

## 온도 추세와 변동 폭

온도 컬럼에서 최근 5개(기본값)/15개 관측의 이동 중앙값을 원본 위에 겹치고, 아래에 이동 표준편차를 표시한다. 원본만 보기로 해제할 수 있다. LH/RH는 계속 좌우로 비교하며 온도 축끼리·표준편차 축끼리 각각 범위를 맞춘다. 시간축 확대는 네 패널에 함께 적용된다.

차종·설비·좌우별 시간순 관측에서 현재값을 포함한 과거 방향으로 계산한다. 선택 날짜의 시작, 10분 초과 공백, 결측에서 창을 초기화하며 5개/15개가 모두 모여야 표시한다. 표준편차는 ddof=0이다. 초/분이 아닌 관측 수 기준이다. 원본/불량점과 CSV·상관계수는 변경하지 않으며, 추세는 시각적 탐색용이다.

## CN7 검토 대상 포함/제외

기본값은 전체 포함이다. 검토 대상 처리에서 제외 모드로 바꾸면 CN7 10/29~30 중 형개 위치 <100 및 사출 시간−충전 시간 >6에 해당하는 18건을 분석에서 제외한다. 해당 조건은 사후 데이터 검토 규칙이며 불량 판정이나 자동 오류 수정이 아니다. 원본 라벨은 모두 Y로 유지한다. 날짜/좌우 선택 범위의 대상·제외·분석 건수를 표시한다. 검토 목록은 제외 모드에서도 원본 상세를 열 수 있다.

전체 포함에서는 검토 양품을 갈색 빈 사각형으로 구분한다. 그래프/이동 통계/상관/CSV는 동일한 행 선택을 사용한다. CSV에는 Data_Review_Flag와 처리 모드 파일명을 추가했다. 상수 컬럼 판단은 비교를 위해 검토 제외 전 제품·좌우 전체 기간을 기준으로 유지한다. RPM 배율 의심 안내는 별도로 표시하고 값은 수정하지 않는다.
