# 제공 자료 원본 보관

사용자가 내려받은 아래 파일의 바이트를 변경하지 않고 보관한다.

- `04. Dataset_Molding.zip`: CSV 8개를 포함하는 제조데이터 패키지. 이 ZIP에서 별도의 0.2초 원시 파형 파일은 찾지 못했다.
- `04.-Guidebook_Molding.pdf`: 108쪽 분석실습 가이드북.

이전 위치의 원본도 `../archive/2026-09-29_tabular_v1/1.injection-molding/`에 보존했다. 새 사본과 보관본의 SHA-256이 동일함을 확인했다. 출처 URL이나 다운로드 시각은 파일 내용만으로 확정하지 않으며, 이 문서는 공식 대회 규정 확인을 대체하지 않는다.

GitHub에는 대용량 원본을 올리지 않는다. 복제한 작업 공간에서는 위 이름으로 이 폴더에 배치한 다음 `../scripts/review_sources.py`를 실행한다. CSV는 ZIP에서 읽으므로 따로 압축을 풀 필요가 없다. ‘원본 보관’은 내려받은 파일이 변경되지 않았다는 뜻이며, CSV 자체가 미가공 센서 데이터라는 뜻은 아니다.
